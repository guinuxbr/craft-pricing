A fast, responsive, and easy-to-use web application for calculating fair, transparent, and sustainable pricing for
handmade crafts, crochet, knitting, sewing, pottery, and artisan goods.

I originally made this for my mum to help her value and price her amazing handmade pieces! ❤️

---

## ✨ Features

- 🧶 **Accurate Craft Calculations**: Automatically computes material cost per gram, total yarn value, labor valuation,
  total production cost, and final recommended selling price.
- 💰 **Configurable Profit Margins**: Tailor your desired business profit margin percentage with instant live
  recalculations.
- 🌍 **Multi-Language Support (i18n)**: Seamless instant switching between English (🇬🇧 EN) and Portuguese (🇧🇷 PT).
- 📋 **One-Click Clipboard Export**: Copy formatted itemized breakdown tables directly to paste into spreadsheets or
  messages.
- 📄 **Instant PDF Export**: Generate and download clean, professional PDF records and invoice summaries with one click
  via jsPDF.
- 🌙 **Dark & Light Mode**: Modern aesthetic with automatic system OS preference detection and persistent preference
  storage.
- ⌨️ **Keyboard Navigation**: Power-user shortcuts for quick, mouse-free calculation and management.
- 📲 **PWA & Offline Capable**: Installable as a progressive web app with Service Worker offline caching.
- 🚀 **Automated CI/CD**: Automatic deployment to GitHub Pages via GitHub Actions with pinned commit SHAs.

## ⌨️ Keyboard Shortcuts

| Key              | Action                                            |
|:-----------------|:--------------------------------------------------|
| <kbd>Enter</kbd> | Calculate price breakdown (when inside any input) |
| <kbd>C</kbd>     | Copy calculated result breakdown to clipboard     |
| <kbd>P</kbd>     | Save / Download PDF summary                       |
| <kbd>L</kbd>     | Clear / Reset form inputs                         |
| <kbd>T</kbd>     | Toggle Dark / Light theme mode                    |
| <kbd>?</kbd>     | Open Keyboard Shortcuts guide                     |
| <kbd>Esc</kbd>   | Close modal dialogues                             |

## 🛠️ Tech Stack

- **HTML5 & Modern Semantics** with ARIA accessibility compliance
- **CSS3 / Modern Variables & Glassmorphism** (responsive down to 320px, dark/light themes, zero layout shift)
- **Vanilla JavaScript (ES6+)** with `@ts-check`, Clipboard API, and LocalStorage
- **jsPDF** for client-side PDF invoice and summary generation
- **Font Awesome 6** & **Google Fonts (Poppins)**
- **GitHub Actions** for automated CI/CD deployment
